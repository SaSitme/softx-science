# SoftX · NEXUS Science

Локальная платформа разбора и проверки данных об экспериментальных однопереходных тонкоплёночных солнечных элементах. Интерфейс объединяет библиотеку публикаций, PDF X-Ray, сопоставление и экспорт.

## Запуск

Требуются Python 3.11+ и CLI MuPDF `mutool` в `PATH` (например, пакет `mupdf-tools` в Debian/Ubuntu).

```bash
cd softx-science
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m softx.app
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). По умолчанию приложение обрабатывает пять демонстрационных PDF с явной маркировкой. Для пустой библиотеки используйте `SOFTX_DEMO=0 python -m softx.app`. `SOFTX_DATA` задаёт каталог базы и PDF, по умолчанию `instance/`. `PORT` меняет порт. Используйте один процесс приложения на каталог базы. Внешние API для извлечения и проверки не требуются.

Для установки на VPS используйте [инструкцию по развёртыванию](deploy/README.md). Ветка `codex/production` содержит исходники действующей сборки s0ftx.ru с профилем высокой полноты.

Параметр `SOFTX_PRIVATE_WORKSPACES=1` открывает отдельную библиотеку в каждом профиле браузера. Временно открыть приложение с чужой сессией можно при наличии её cookie, поэтому для отдельной рабочей области на общем компьютере используйте другой профиль браузера. Удаление отдельного результата скрывает его из рабочих таблиц. Удаление статьи убирает все её PDF и связанные записи из текущей рабочей области.

### Локальный ИИ для сложных фрагментов

Запустите совместимый с OpenAI Chat Completions сервер на локальном адресе, например `llama-server` с моделью GGUF. Затем запустите SoftX с тем же портом модели.

```bash
llama-server -m /путь/к/модели.gguf --host 127.0.0.1 --port 8090 --alias local
SOFTX_LOCAL_ONLY=1 SOFTX_LOCAL_AI_PORT=8090 python -m softx.app
```

Модель выбирает метрику для конкретного числа и единицы из текстового слоя PDF. SoftX проверяет совместимость единиц и сохраняет координаты фрагментов. Подтверждённые текстом результаты Qwen получают автоматический статус. Неоднозначные записи отмечаются «Требует проверки». Способ извлечения сохраняется как `local_ai_pdf_quote`. По умолчанию SoftX отправляет в локальную модель до 12 пакетов кандидатов на PDF. Лимит задаётся через `SOFTX_LOCAL_MAX_BATCHES`. Если локальная модель недоступна, SoftX продолжает обработку обычным парсером.

### Локальное распознавание сканов

Установите Tesseract и модель языка документа (например, `tesseract-ocr` и `tesseract-ocr-eng` в Debian/Ubuntu). Включите `SOFTX_OCR=1`. Модель языка задаётся в `SOFTX_OCR_LANG` и по умолчанию равна `eng`. OCR читает страницы без текстового слоя и изображения рядом с подписями таблиц и рисунков. Значения OCR помечаются «Требует проверки» и связаны с местом на исходной странице.

### OpenAI API для сложных фрагментов

OpenAI включается явно через `SOFTX_OPENAI_MODEL`. Введите ключ в терминале без отображения ввода и запустите приложение.

```bash
read -rs OPENAI_API_KEY
export OPENAI_API_KEY
SOFTX_OPENAI_MODEL=gpt-5-mini python -m softx.app
```

Для запуска из сервиса можно передать секрет через `SOFTX_OPENAI_API_KEY_FILE`. Ключ используется только на сервере. В OpenAI отправляются короткие фрагменты текстового слоя вокруг ещё не извлечённых значений. Модель выбирает допустимый код метрики из списка, а число, единица и координаты берутся из PDF. По умолчанию отправляется до 12 запросов на PDF и до 10 фрагментов в запросе. Лимит настраивается через `SOFTX_OPENAI_MAX_BATCHES`. Результаты помечаются «Требует проверки» и доступны в «Данных» через фильтр «Предложения OpenAI». При недоступности API остаются результаты локального парсера.

### DeepSeek API

DeepSeek обрабатывает оставшиеся текстовые фрагменты после локальной модели. При `SOFTX_DEEPSEEK_VISION=1` он также предлагает связи чисел и единиц на вырезках таблиц и рисунков. Значения и координаты проверяются по локальному OCR. `SOFTX_DEEPSEEK_AUTOMATIC=1` включает DeepSeek для загрузок и повторной обработки без отдельной галочки. В обычном режиме способ обработки можно выбрать для каждого PDF.

```bash
SOFTX_DEEPSEEK_MODEL=deepseek-flash SOFTX_DEEPSEEK_VISION=1 \
SOFTX_DEEPSEEK_API_KEY_FILE=/путь/к/deepseek.key python -m softx.app
```

По умолчанию на PDF приходится до 12 текстовых запросов и 3 вырезок изображений. Лимиты задаются через `SOFTX_DEEPSEEK_MAX_BATCHES` и `SOFTX_DEEPSEEK_MAX_IMAGES`. Ключ хранится только на сервере. При `SOFTX_LOCAL_ONLY=1` облачные запросы отключены.

В PDF X-Ray кнопка «Добавить запись из PDF» сохраняет выделение и переписанные с него данные. Запись можно оставить в очереди «Только требуют проверки» или подтвердить, сверив с оригиналом.

Модель может добавить показатель, когда локальный текст или OCR связывает напечатанное число и его единицу с названием показателя. Для изображения таблицы связь проверяется по заголовку столбца. Полный экспорт сохраняет исходные записи и ссылки на их источники.

Сравнивайте точность и полноту на свежих базах с одинаковыми PDF и эталоном. Для замера запустите команду из раздела «Проверка и экспорт» с переменными выбранного провайдера.

## Демонстрация

1. В «Публикациях» загрузите пакет из `fixtures/`. Проверьте статус повреждённого PDF, исключение тандема и теоретической работы. Кнопка с поворотом повторяет обработку выбранного файла. Повторная загрузка того же SHA-256 открывает ту же запись в библиотеке.
2. Откройте «Perovskite thin films under AM1.5G». В PDF X-Ray щёлкните по записи Voc, увеличьте масштаб, поверните страницу и щёлкните по выделению. Раскройте приборы и слои. У PCE 16 % выберите прибор и измерение из кандидатов. Проверьте исходное значение и историю.
3. В разделе «Данные» найдите `Voc` и переключите происхождение на «Цитируемый». Откройте ссылку на запись.
4. В «Сопоставлении» выберите PCE приборов с разными ходами. В «Экспорт данных» скачайте ZIP со снимком базы или отчёт JSON.
5. Нажмите корзину в библиотеке и подтвердите удаление тестовой статьи. Её PDF и связанные записи исчезнут из текущей рабочей области.

## Архитектура

Сервер сохраняет показатели из откалиброванных кривых со статусом «Требует проверки» и ссылкой на рисунок. Voc и Jsc определяются по пересечениям осей ВАХ, FF — по максимуму мощности кусочно-линейной кривой. Для КПД требуется указанная в PDF интенсивность освещения этого измерения. Из EQE рассчитывается плотность тока в пределах наблюдаемого диапазона длин волн. T80 определяется по пересечению 80% на явно подписанной кривой удержания эффективности. Для ранее загруженных PDF используйте «Повторить обработку».

Flask обслуживает UI и API. Пул фоновых задач обрабатывает файлы независимо, очередь и состояния хранятся в SQLite с внешними ключами и WAL. pypdf читает метаданные и геометрию страниц, MuPDF извлекает координаты символов и векторные команды и визуализирует исходную страницу. Клиент использует SVG-слой источников и единую матрицу с оригиналом для поворота и масштабирования. Неизменные оригиналы хранятся по SHA-256.

`pdf.py` отвечает за файлы и координаты, `store.py` за реляционные операции, `validation.py` за протокол выполнения правил и сохранение замечаний. Предметный реестр метрик и единиц находится в `domain.py`, эвристики заполнения научной схемы в `extract.py`, расчёты в `rules.py`, `spectrum.py` и `derived.py`. Эти модули используют интерфейсы PDF и хранилища для подстановки предметной логики на уровне приложения.

## Проверка и экспорт

Для E2E нужен Chromium и Playwright. Путь к Chromium можно задать через `CHROMIUM`. Тест поднимает временную SQLite и локальный HTTP-сервер и проверяет загрузку, UI и скачанные файлы.

```bash
python -m pip install -r requirements-dev.txt
python tests/e2e.py
```

Выгрузка текущего корпуса в каталог, новый снимок тестов и оценка исходного извлечения:

```bash
python -m softx.cli export-local
SOFTX_DATA="$(mktemp -d)" python -m softx.cli export --fixtures
python tests/evaluate.py --output export/evaluation.json
```

На предоставленном корпусе `dev` результаты можно посчитать на свежей базе. При добавлении `SOFTX_LOCAL_AI_PORT=8090` перед командой используется запущенная локальная модель.

```bash
SOFTX_DATA="$(mktemp -d)" python tests/evaluate_dev.py --pdfs /путь/к/dev --gold /путь/к/dev_gold/results.csv --output export/dev_comparison.json
```

В репозитории доступны [паспорт данных](DATA_PASSPORT.md), [отчёт о приёмке](ACCEPTANCE.md), [полный снимок](export/dataset.json), [книга XLSX](export/dataset.xlsx) и [отчёт о замечаниях](export/validation_report.json).
