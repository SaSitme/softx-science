# Паспорт данных SoftX

Версия схемы 1. [Формальный словарь таблиц и полей](data_passport.json) содержит типы SQLite, признаки обязательности, ключи, связи и значения по умолчанию. [SQL-схема](softx/schema.sql) задаёт ограничения, индексы и защиту опубликованных значений.

## Сущности и кратность

| Сущность | Хранилище | Назначение |
| --- | --- | --- |
| Publication | `publication` | Библиографическая запись и решение по корпусу. Может иметь несколько PDF с одним явно указанным DOI. Ключ в экспорте `id`. |
| PdfVersion | `pdf_version` | Версия файла. `id = sha256`. Метаданные, очередь, состояние обработки, ошибки страниц. |
| Material | `material` | Состав и класс, размерность, добавки, Eg и метод определения Eg. |
| Device | `device` | Прибор публикации, метка, роль, архитектура, подложка, площадь, инкапсуляция. |
| DeviceLayer | `device_layer` | Слой прибора, исходное обозначение материала, порядок, толщина и параметры изготовления. |
| Measurement | `measurement` | Условия эксперимента для прибора. Ходы `forward` и `reverse` образуют разные измерения. |
| MeasurementResult | `measurement_result` | Значение метрики с отдельными ссылками на публикацию, PDF, прибор, измерение и материал. Неоднозначные связи допускают список кандидатов. |
| SourceReference | `source_reference` | Фрагмент конкретной версии PDF. `result_source` и `plot_source` образуют связи многие-ко-многим. |
| PlotDataset | `plot_dataset` | Одна серия рисунка с калибровкой, исходными координатами и физическими точками. `result_plot` связывает полученный показатель с входной серией. |
| ValidationIssue | `validation_issue` | Результат запуска правила со значениями, порогом, статусом и гипотезой. Связи хранятся в `issue_result` и `issue_source`. |
| AuditLog | `audit_log` | История изменённых полей, значения до и после, автор и время UTC. Для одиночного локального пользователя автор `local-reviewer`. |

## Значения и происхождение

- `raw_value` и `raw_unit` хранят опубликованную запись. `raw_record` сохраняет исходную агрегацию, знак неравенства, диапазон, разброс, направление и при наличии размер выборки и временную точку. SQL-триггер блокирует изменения этих трёх полей. `metric_value` и `metric_unit` хранят текущее значение. `normalized_value` и `normalized_unit` вычисляются для однозначно интерпретируемых скаляров.
- `value_state` принимает `numeric`, `numeric_zero`, `missing`, `ambiguous`, `unparseable`. Для отсутствующих данных используется `null`. В таблицах явные прочерки и N/A сохраняются как результат с состоянием `missing`. Проблемы страницы отражаются в `failed_pages` с перечнем полей для просмотра.
- `aggregation` принимает `champion`, `mean`, `median`, `single`, `unknown`. `extraction_status` принимает «Извлечено автоматически», «Подтверждено пользователем», «Требует проверки».
- `result_origin` принимает `primary` или `cited` независимо от `acquisition_method`. Для цитат `cited_publication_id` указывает на библиографическую запись при распознанном DOI. При отсутствии доказуемой ссылки сохраняется `null`.
- `acquisition_method` принимает `published_numeric`, `digitized_plot`, `calculated`, `assumption`. Для расчёта `formula` и `calculation_inputs` описывают метод и параметры, `input_result_ids` и `result_plot` задают связи со входами соответствующего типа. `assumption_basis` предназначено для обоснования предположения. Проверка КПД требует опубликованную Pin с фрагментом PDF.
- Ссылки на источник используют `source_type` из `text`, `table_cell`, `table_header`, `footnote`, `figure`, `caption` и `fragment_role` из `value`, `unit`, `sample_label`, `condition`. Единицы в заголовках и метки образцов имеют самостоятельные ссылки.

## Единицы

| Величина | Результат нормализации |
| --- | --- |
| PCE, FF, HI | % |
| Voc | V |
| Jsc, Jsc_EQE | mA/cm² |
| Eg | eV |
| Толщина | nm |
| Площадь | cm² |
| Время, T80 | h |
| Pin | mW/cm² |
| Rs, Rsh | Ω или Ω·cm² согласно виду исходной величины |

Преобразования и синонимы единиц заданы в [реестре предметной области](softx/domain.py). Для долей PCE и FF нужна явная маркировка единицы. Значения диапазонов и ограничений остаются типизированными исходными величинами. Сопротивление и удельное сопротивление по площади имеют разные размерности.

## Система координат и графики

Нумерация страниц начинается с 1. Координаты `bbox` и `plot_bbox` имеют формат `[x_min, y_min, x_max, y_max]` в исходном пространстве PDF. Ось Y направлена вверх. Параметры страницы содержат MediaBox, видимую область CropBox, UserUnit и исходный поворот. Клиент применяет обратное направление Y, масштаб, поворот страницы и пользовательский поворот одной матрицей к оригиналу и векторному слою выделений.

В `axes.x` и `axes.y` хранятся `p0,p1` в координатах PDF, `v0,v1` в физических единицах, `scale` из `linear|log`, `unit` и при заполнении `label`. Точка хранит `px,py` в PDF и `x,y` после пересчёта. Линейная шкала интерполирует значения, логарифмическая шкала интерполирует их логарифмы. Все серии имеют `is_approximate = 1`. Для векторной линейной серии `uncertainty` рассчитывается как половина ширины штриха в PDF, умноженная на изменение физического значения на единицу координат. В остальных случаях `uncertainty_method` описывает причину недоступности оценки.

Интегрирование EQE использует трапеции на объединённой сетке спектра и измеренных длин волн. По оси Y принимаются проценты или доли. Интеграл ограничен оцифрованным диапазоном, который сохраняется в `calculation_inputs.wavelength_nm`. Для сравнения с ВАХ пользователь подтверждает покрытие значимого отклика. T80 вычисляется линейной интерполяцией первого пересечения уровня 80% кривой удержания КПД при наличии начального значения около 100% на t=0.

[Эталонный спектр и атрибуция](softx/reference/DATA_NOTICE.md).

## Проверки Science Detective

Значения для проверок берутся из текущих нормализованных результатов с доказуемой привязкой к прибору, материалу или измерению в зависимости от правила. Замечание имеет один из уровней `error`, `warning`, `info`, `not_applicable`. Результаты проверки получают состояния `open`, `passed`, `resolved`, `not_applicable` или `superseded`.

| Код | Условие, порог и область применения |
| --- | --- |
| `PCE_CONSISTENCY` | `100 × Voc × abs(Jsc) × (FF/100) / Pin`. Предупреждение при `abs(PCE − PCE_calc) / abs(PCE_calc) > 0.03`. Нужна положительная Pin с источником для того же измерения и отдельный ход. |
| `VOC_BANDGAP` | Ошибка при `Voc ≥ Eg/q`. Eg в eV и напряжение в V. Нужна однозначная связь с материалом прибора. |
| `PHYSICAL_RANGE` | `0 < FF ≤ 100%`, `0 ≤ PCE ≤ 100%`. Для Jsc используется энергетическая граница `abs(Jsc) × Eg/q ≤ Pin` при наличии Eg и подтверждённой Pin в рамках модели одного носителя на поглощённый фотон. |
| `SHOCKLEY_QUEISSER` | При подтверждённом AM1.5G 100 мВт/см² сравнивает PCE и модуль Jsc с численным пределом детального баланса для данного Eg. Модель идеального однопереходного прибора использует одну излучающую сторону, поглощение единицы выше Eg и опубликованную температуру, если она распознана. При неизвестной температуре предел рассчитывается для явно обозначенного эталонного ориентира 25 °C. |
| `EQE_JSC` | `abs(abs(Jsc_EQE) − abs(Jsc_JV))/abs(Jsc_JV) > 0.05`. Нужны один прибор, подтверждённое измерение и ход, единая категория агрегации и ненулевой Jsc. Для расчёта с графика требуется подтверждение спектрального покрытия. |
| `BATCH_CHAMPION` | Предупреждение, если `champion < mean` или превышает `mean + spread` при известном `spread`. Нужны совпадающие явно обозначенные партия, измерительные условия, ход и метрика. |
| `SCAN_ISOLATION` | Сопоставляет исходное направление с текущим направлением привязанного измерения. Предупреждение при разных явно указанных направлениях. |
| `CROSS_SOURCE` | Для разных видов источника сравнивает одну метрику, прибор, измерение, ход и известную агрегацию. Абсолютный допуск складывается из половины младших опубликованных разрядов и оценённых погрешностей оцифровки. Для оцифрованного значения с неизвестной погрешностью сравнение помечается как невозможное. |

[Модель детального баланса для однопереходных элементов при AM1.5G](https://doi.org/10.1016/j.solener.2016.02.015).

## Сопоставление

Прямое сравнение требует две однозначные первичные записи из включённых публикаций, одинаковые метрику, единицу, класс материала, тип прибора, определение площади, известную агрегацию и ход. Освещение должно быть явно подтверждено как AM1.5G 100 мВт/см². Сопоставимыми считаются положительные площади в см² при `abs(a − b) / max(a, b) ≤ 0.05`. Допуск 5% выбран для реализации критерия сопоставимости площади ТЗ. Сертифицированные результаты и T80 имеют свои вкладки. Для T80 дополнительно нужны совпадающие протокол и условия старения. Интерфейс показывает проваленные критерии и открывает обе записи в PDF X-Ray.

## Форматы выгрузки

JSON сохраняет типы и вложенные поля, NDJSON содержит объекты `{table,row}`. В реляционном CSV одна таблица соответствует одному файлу. В XLSX лист соответствует таблице. Длинные строки сверх лимита Excel помечаются, полное поле доступно в JSON и CSV. В CSV текст, который табличный редактор может выполнить как формулу, экранируется апострофом. Цифровой оригинал PDF и вырезка графика размещаются в `assets/<pdf_version_id>/`.
